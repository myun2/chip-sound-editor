CHIP SOUND EDITOR

小節

番号で小節を選んで編集する。小節は 64 個まで作れ、どのトラックにも置ける。タブは、その小節を鳴らすトラック（波形）。
マスをクリックで音を置く / 消す。ドラッグで続けて置ける。下の帯は音量（3 段階）。

「再生」は、この小節を繰り返す。曲の中で使っている小節なら、同じ位置のほかのトラックも一緒に鳴り、薄く重ねて表示される。
「この小節だけ」は、ほかのトラックを鳴らさずにこの小節だけを繰り返す（ミュート中でも鳴る）。
Space = 再生 / 停止、Shift + Space = この小節だけ、1〜4 = タブの切り替え、Ctrl / ⌘ + Z = 元に戻す。

置く小節

マスを選んでから番号を押すと、その位置に小節を置き、その小節を 1 回鳴らす（置くと次の位置へ進む）。同じ小節を何度でも、どのトラックにでも置ける。
「休み」で空にする。マスのダブルクリックか「この小節を編集」で、その小節の編集に移る。

再生は、選んでいるマスの位置から始まる。上の番号を押しても位置を選べる。
Space = 再生 / 停止、Ctrl / ⌘ + Z = 元に戻す。
