# Chip Sound Editor

チップチューン風のシーケンサー (Generated by Claude)

4 つのトラックを重ねて短い曲やジングルを作る。[Dot Game Platform](https://github.com/myun2/dot-game-platform) の音源を切り出して作ったもの。ブラウザだけで動く（ビルド不要・素の JavaScript）。

```
open index.html            # そのままでも動く
python3 -m http.server 8953 && open http://localhost:8953/
```

## できること

- 4 トラックを同時に再生する。波形はトラックごとに決まっていて、矩形波 50% / 矩形波 25% / 三角波 / ノイズ が 1 つずつ。それぞれミュートとソロができる。
- トラックは波形の名前がついたタブで切り替え、選んだトラックをピアノロールで編集する。音程は C3〜B6、音量は 3 段階。ほかのトラックの音は薄く重ねて表示される。
- テンポは曲全体で 1 つ、BPM で指定する（20〜900）。1 ステップ = 16 分音符、1 小節 = 16 ステップ。
- 長さは 1〜16 小節。短くしても、はみ出した部分の音は消えずに残る。
- 上の小節番号を押すと、その小節から再生できる。小節単位でコピー / 貼り付け / 消去できる（別のトラックにも貼れる）。
- `Space` で再生 / 停止、`1`〜`4` でトラック切り替え、`Ctrl/⌘ + Z` で元に戻す。
- `見本の曲` で、4 トラックを使った 4 小節の例をいつでも開ける（DOT JUMP の BGM にベースとドラムを足したもの。矩形波 25% は空けてある）。
- 編集内容は自動でブラウザに保存される。`保存 (.json)` でファイルやクリップボードに書き出せる。

## 構成

| ファイル | 役割 |
| --- | --- |
| `sound.js` | 曲のデータ、保存形式の読み書き、再生の手順（シーケンサ）。画面にも音の出力先にも依存しない |
| `audio.js` | WebAudio の 4 チャンネル音源。「このチャンネルをこの音で」を受け取って鳴らすだけ |
| `editor.js` | 編集画面 |
| `tests/sound.cjs` | `sound.js` の検査 |

```
node tests/sound.cjs
```

`sound.js` と `audio.js` は画面なしでも使える。ゲームに組み込むなら、毎フレーム `tick()` を呼ぶ。

```js
const song = ChipSound.decode(json);              // 保存したデータ
const audio = ChipAudio.create();
const seq = ChipSound.createSequencer(song, (ch, wave, freq, vol) => audio.voice(ch, wave, freq, vol));

audio.resume();            // クリックやキー入力のあとで 1 回（ブラウザの制限）
seq.state.loop = true;     // 最後まで行ったら頭に戻る（false なら止まる）
seq.play();                // 先頭から。seq.play(16) なら 2 小節目から
seq.tick();                // 毎秒 60 回
seq.stop();
```

## データの形

```json
{
  "chip": 2, "bpm": 120, "bars": 2,
  "tracks": [{ "m": 0, "n": "1c3000…" }, { "m": 0, "n": "" }, { "m": 0, "n": "" }, { "m": 0, "n": "" }]
}
```

- `bpm` = テンポ、`bars` = 長さ（小節数）。`tracks` は 4 つで、並び順がそのままチャンネルと波形（矩形波 50%、矩形波 25%、三角波、ノイズ の順）。
- `m` = ミュート（0 / 1）。ソロは保存しない。
- `n` = ステップを先頭から並べたもの。1 ステップは 16 進 3 桁で、前 2 桁が音程（00 = C3 〜 2f = B6）、最後の 1 桁が音量（0 = 無音 〜 3）。末尾の無音は省く。

以前の形式（`"chip": 1`、効果音 32 個）や DOT のカートリッジ（`.dot.json`）も読み込める。その場合は 1 小節の曲として読み、中身のある効果音を先頭から順に、同じ波形のトラックへ入れる（ふさがっていれば空いているトラックへ。4 つまで）。

## 知っておくこと

- 音が出るのは、ページを一度クリックするかキーを押したあと（ブラウザの制限）。
- 1 トラックが同時に鳴らせるのは 1 音。和音は複数のトラックで作る。
- 波形は変えられない。同じ波形を 2 つ重ねることはできない。
- 1 ステップに置けるのは音程と音量だけ。音の長さの指定はなく、同じ音を続けて置くとつながって聞こえる。
- ステップの切り替えは 1/60 秒単位。テンポが割り切れないときは、ステップの長さを 1 フレームずつ前後させて平均を合わせる。
- 再生のテンポはブラウザのタイマーまかせなので、わずかに揺れる。
- DOT へ持っていく書き出しはない（DOT の効果音は 16 ステップ・1 音ずつで、形が違う）。
- WAV などの音声ファイルへの書き出しはない。
