# Chip Sound Editor

チップチューン風のシーケンサー (Generated by Claude)

小節を作って並べ、4 つのトラックを重ねて短い曲やジングルを作る。[Dot Game Platform](https://github.com/myun2/dot-game-platform) の音源を切り出して作ったもの。ブラウザだけで動く（ビルド不要・素の JavaScript）。

```
open index.html            # そのままでも動く
python3 -m http.server 8953 && open http://localhost:8953/
```

## できること

2 つのモードを行き来して曲を作る。

**小節を編集** — 1 小節（16 ステップ）ぶんの音を作る。

- 小節は曲全体で 64 個まで。番号で選び、ピアノロールで編集する。音程は C3〜B6、音量は 3 段階。
- 小節はトラックを区別しない。どのトラックにも置けて、置いたトラックの波形で鳴る。
- タブで、鳴らすトラックを選ぶ。波形はトラックごとに決まっていて、矩形波 50% / 矩形波 25% / 三角波 / ノイズ が 1 つずつ。
- 「再生」は、その小節を繰り返す。選んでいるトラックが曲の中で使っている小節なら、同じ位置のほかのトラックも一緒に鳴り、薄く重ねて表示される。
- 「この小節だけ」（`Shift + Space`）は、ほかのトラックを鳴らさずにその小節だけを繰り返す。ミュート中のトラックでも鳴る。
- 小節のコピー / 貼り付け / 消去。どのトラックのどこで使っているかも表示される。

**小節を並べる** — 作った小節を、曲の位置ごとに置いていく。

- 4 トラック × 曲の長さ（1〜64 小節）のマスに、小節の番号を置く。同じ小節を何度でも、どのトラックにでも置ける。空きは休み。
- マスを選んで番号を押すと置かれ、次の位置へ進む。置いた小節は、そのトラックの波形で 1 回鳴る（曲を流している最中は鳴らさない）。マスのダブルクリックで、その小節の編集に移る。
- 再生は選んでいる位置から。トラックごとにミュートとソロ。

共通:

- テンポは曲全体で 1 つ、BPM で指定する（20〜900）。1 ステップ = 16 分音符。
- `Space` で再生 / 停止、`Ctrl/⌘ + Z` で元に戻す。編集モードでは `1`〜`4` でタブを切り替える。
- `見本の曲` で、小節を使い回した 4 小節の例をいつでも開ける（DOT JUMP の BGM にベースとドラムを足したもの。矩形波 25% は空けてある）。
- 編集内容は自動でブラウザに保存される。`保存 (.json)` でファイルやクリップボードに書き出せる。

## 構成

| ファイル | 役割 |
| --- | --- |
| `sound.js` | 曲のデータ、保存形式の読み書き、再生の手順（シーケンサ）。画面にも音の出力先にも依存しない |
| `audio.js` | WebAudio の 4 チャンネル音源。「このチャンネルをこの音で」を受け取って鳴らすだけ |
| `editor.js` | 編集画面 |
| `tests/sound.cjs` | `sound.js` の検査 |

```
node tests/sound.cjs
```

`sound.js` と `audio.js` は画面なしでも使える。ゲームに組み込むなら、毎フレーム `tick()` を呼ぶ。

```js
const song = ChipSound.decode(json);              // 保存したデータ
const audio = ChipAudio.create();
const seq = ChipSound.createSequencer(song, (ch, wave, freq, vol) => audio.voice(ch, wave, freq, vol));

audio.resume();            // クリックやキー入力のあとで 1 回（ブラウザの制限）
seq.state.loop = true;     // 最後まで行ったら頭に戻る（false なら止まる）
seq.play();                // 先頭から。seq.play(2) なら 3 小節目から
seq.tick();                // 毎秒 60 回
seq.stop();

seq.audition(0, 2);        // 小節 2 だけを、トラック 1 の波形で繰り返し鳴らす（曲に置いていなくてもよい）
seq.audition(0, 2, 3);     // 同じ小節を、曲の 4 小節目のほかのトラックと重ねて鳴らす
```

## データの形

```json
{
  "chip": 4, "bpm": 90, "length": 4,
  "patterns": ["0c2000132…", "052000…", "003000…"],
  "tracks": [
    { "m": 0, "o": [1, 2, 1, 2] },
    { "m": 0, "o": [] },
    { "m": 0, "o": [3, 3, 3, 3] },
    { "m": 0, "o": [] }
  ]
}
```

- `bpm` = テンポ、`length` = 曲の長さ（小節数）。
- `patterns` = 小節（64 個まで）。1 つの小節は 16 ステップを先頭から並べたもので、1 ステップは 16 進 3 桁。前 2 桁が音程（00 = C3 〜 2f = B6）、最後の 1 桁が音量（0 = 無音 〜 3）。
- `tracks` は 4 つで、並び順がそのままチャンネルと波形（矩形波 50%、矩形波 25%、三角波、ノイズ の順）。
- `m` = ミュート（0 / 1）。ソロは保存しない。
- `o` = 並び。曲の位置ごとに、鳴らす小節の番号（1〜64。0 は休み）。
- `patterns` も `o` も、末尾の空きは省く。

以前の形式も読み込める。どれも、同じ中身の小節は 1 つにまとめる。

- `"chip": 3`（小節がトラックごとに別）は、小節を 1 つの置き場にまとめる。番号は変わる。
- `"chip": 2`（小節に分かれていない 4 トラック）は、16 ステップごとに小節へ切り分ける。
- `"chip": 1`（効果音 32 個）や DOT のカートリッジ（`.dot.json`）は 1 小節の曲として読み、中身のある効果音を先頭から順に、同じ波形のトラックへ入れる（ふさがっていれば空いているトラックへ。4 つまで）。

## 知っておくこと

- 音が出るのは、ページを一度クリックするかキーを押したあと（ブラウザの制限）。
- 1 トラックが同時に鳴らせるのは 1 音。和音は複数のトラックで作る。
- 波形は変えられない。同じ波形を 2 つ重ねることはできない。
- 小節の長さは 16 ステップで固定。
- 小節を書き換えると、その小節を置いたすべての位置が、どのトラックでも変わる。一部だけ変えたいときは、コピーして別の番号に貼ってから直す。
- 1 ステップに置けるのは音程と音量だけ。音の長さの指定はなく、同じ音を続けて置くとつながって聞こえる。
- ステップの切り替えは 1/60 秒単位。テンポが割り切れないときは、ステップの長さを 1 フレームずつ前後させて平均を合わせる。
- 再生のテンポはブラウザのタイマーまかせなので、わずかに揺れる。
- DOT へ持っていく書き出しはない（DOT の効果音は 16 ステップ・1 音ずつで、形が違う）。
- WAV などの音声ファイルへの書き出しはない。
